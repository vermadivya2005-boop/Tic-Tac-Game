# 🎮 Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. This project allows two players to play the classic Tic-Tac-Toe game in a web browser.

## ✨ Features

* Two-player gameplay
* Interactive game board
* Winner detection
* Reset game functionality
* New game option
* Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing!
